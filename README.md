# Week 4 – Comprehensive Data Analysis and Reporting using R

## 📌 Project Overview

This project represents the final week of the internship and integrates the data analysis work completed throughout the previous three weeks.

The project uses the **Titanic Passenger Dataset** and follows a complete data analytics workflow, beginning with data preparation and cleaning, followed by visualization, statistical analysis, and predictive modeling.

The purpose of this final project is to consolidate the previous analyses into a cohesive data-driven report and communicate the findings, statistical results, model performance, and practical implications in a clear and structured manner.

---

## 🎯 Project Objectives

The main objectives of this project were to:

- Clean and preprocess the Titanic dataset.
- Handle missing values and identify potential outliers.
- Perform exploratory data analysis.
- Create informative data visualizations.
- Conduct statistical and hypothesis testing.
- Develop a predictive classification model.
- Evaluate the performance of the predictive model.
- Interpret the results and identify important factors related to passenger survival.
- Present the complete analysis in a professional final report.

---

## 📊 Dataset

**Dataset:** Titanic Passenger Dataset

The dataset contains information about passengers aboard the Titanic, including:

- Passenger Class
- Sex
- Age
- Fare
- Survival Status
- Embarkation Port
- Family-related information

### Dataset Files

- `titanic_raw.csv` – Original Titanic dataset.
- `titanic_cleaned.csv` – Cleaned and preprocessed dataset used for analysis.
